# AIディープフェイク詐欺デモ — 仕様書

## 概要

| 項目 | 内容 |
|------|------|
| 用途 | FleGrowth × シブカツ AIワークショップ 教育用デモ |
| 目的 | 写真1枚＋音声数秒で本人そっくりの動画が作れる事実を体感させ、AI詐欺への警戒心を高める |
| 操作者 | 講師（プロジェクター投影） |
| 対象 | 高齢者参加者 |

## 実現すること

写真と音声データから人物を登録し、任意のテキストをその人物が話しているかのような動画を生成する**実働システム**。

## システム構成

```
┌─────────────┐
│  ブラウザ UI  │  ← HTML/CSS/JS（単一ページ or 軽量フレームワーク）
└──────┬──────┘
       │ fetch
┌──────▼──────┐
│  バックエンド  │  ← Node.js or Python（API キー管理・中継）
└──────┬──────┘
       │
  ┌────┴─────────────────┐
  │                      │
  ▼                      ▼
ElevenLabs API       D-ID API
（音声クローン＋TTS）  （写真＋音声→動画生成）
```

## 画面フロー

### Step 1 — 人物登録

| 項目 | 内容 |
|------|------|
| 操作 | 顔写真をアップロード + 音声サンプル（数秒〜1分程度）をアップロード |
| 処理 | ElevenLabs API で音声クローン（Voice Clone）を作成し、voice_id を取得 |
| 表示 | 登録完了後、人物名・写真サムネイル・音声プレビューを表示 |

### Step 2 — セリフ入力

| 項目 | 内容 |
|------|------|
| 操作 | テキストエリアにセリフを入力（デフォルトテキストあり） |
| デフォルトセリフ | 下記参照 |

```
お母さん、急いで。
ちょっとトラブルがあって、
今日中に50万円振り込んでほしいんだ。
口座番号送るね。
```

### Step 3 — 動画生成

| 項目 | 内容 |
|------|------|
| 処理① | ElevenLabs TTS API：セリフテキスト → クローン音声で音声ファイル生成 |
| 処理② | D-ID API：顔写真 + 生成音声 → トーキングヘッド動画を生成 |
| 表示 | 生成中はプログレス表示（音声生成中… → 動画合成中… → 完了） |
| 所要時間 | 合計 10〜30秒程度（API レスポンス依存） |

### Step 4 — 結果表示

| 項目 | 内容 |
|------|------|
| 表示 | 生成された動画を再生 |
| 警告 | 再生後に赤い警告バナーをフェードイン表示 |
| 警告文 | `⚠️ これはAIが生成したフェイク映像です — 写真1枚と数秒の音声だけで作成されました` |

## API 選定

### 音声クローン＋TTS：ElevenLabs

| 項目 | 内容 |
|------|------|
| 選定理由 | 音声品質が最も高い（業界評価1位）、日本語対応、1〜2分のサンプルで即時クローン可能 |
| 使用機能 | Instant Voice Cloning + Text-to-Speech |
| 必要プラン | API Pro（$99/月、100クレジット） |
| 必要サンプル | 1〜2分のクリアな音声 |
| 日本語対応 | 対応済（32言語以上） |
| 公式ドキュメント | https://elevenlabs.io/docs |

#### 代替候補

| サービス | 特徴 | 備考 |
|----------|------|------|
| Resemble.AI | 3〜10秒でクローン可能、$30/月〜 | サンプル短くてよいが品質はElevenLabsに劣る |
| Murf.AI | $0.01/分、日本語対応 | API が比較的新しい |

### 動画生成：D-ID

| 項目 | 内容 |
|------|------|
| 選定理由 | 写真＋音声→動画のAPIが明快、価格が手頃、統合が容易 |
| 使用機能 | Talks API（写真 + 音声ファイル → 動画） |
| 必要プラン | Lite $5.90/月〜（ウォーターマークあり）or Pro（要問合せ） |
| 入力 | 顔写真（JPEG/PNG）+ 音声ファイル（MP3/WAV） |
| 出力 | MP4 動画（リップシンク済み） |
| 公式ドキュメント | https://docs.d-id.com |

#### 代替候補

| サービス | 特徴 | 備考 |
|----------|------|------|
| HeyGen | 高品質、40言語対応、$99/月〜 | 品質は高いがコストも高い |
| Hedra | リアルタイム対応、$0.05/分 | 新興サービス、安定性要確認 |

## API 処理フロー（詳細）

```
1. 人物登録
   POST /v1/voices/add (ElevenLabs)
   ├─ body: { name, files: [audio_sample] }
   └─ response: { voice_id }

2. 音声生成
   POST /v1/text-to-speech/{voice_id} (ElevenLabs)
   ├─ body: { text, model_id: "eleven_multilingual_v2" }
   └─ response: audio/mpeg (バイナリ)

3. 動画生成
   POST /v1/talks (D-ID)
   ├─ body: { source_url: photo_url, audio_url: audio_url }
   └─ response: { id, status }

4. 動画取得（ポーリング）
   GET /v1/talks/{id} (D-ID)
   └─ response: { status: "done", result_url }
```

## 倫理・安全上の制約

1. **教育目的限定** — 「教育用デモ」バッジと免責テキストを全画面で常時表示
2. **データ非保存** — アップロードされた写真・音声はセッション終了後に破棄（サーバー側に永続保存しない）
3. **API キー管理** — フロントエンドにAPIキーを埋め込まない（バックエンド経由）
4. **生成動画の管理** — 生成された動画URLはセッション中のみ有効。ダウンロード機能は提供しない
5. **利用同意** — デモ開始前に「教育目的であること」の確認ダイアログを表示
